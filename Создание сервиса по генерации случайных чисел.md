# 1. актуальность работы

Генерация случайных чисел является важной составляющей безопасности встроенных систем и аппаратных платформ, поскольку используется при создании криптографических ключей, формировании nonce, инициализации генераторов псевдослучайных чисел и выполнении протоколов аутентификации.

Проект OpenTitan предоставляет аппаратные механизмы обеспечения безопасности, в том числе аппаратный генератор случайных чисел и криптографические компоненты.

# 2. Цель

Цель работы: разработать UART-сервис генерации случайных чисел для программной платформы OpenTitan с FreeRTOS. Сервис будет приниматб запрос через UART, генерировать случайные данные и возвращать их клиенту.

# 3. возможные способы реализации

(более подробно про генерацию случайных чисел можно посмотреть в файле «генерация случайных чисел в opentitan.md»)

Способ 1. Использование аппаратной подсистемы RNG

Использовать цепочку ENTROPY_SRC → CSRNG → EDN либо поддерживаемый программный интерфейс CSRNG. Источник энтропии обеспечивает исходные случайные данные, CSRNG формирует криптографически стойкую последовательность, а EDN распределяет её потребителям. Это предпочтительный вариант для сервиса, ориентированного на безопасность.

Способ 2. Программный DRBG

Использовать программный детерминированный генератор случайных битов (DRBG), инициализируемый начальными данными из доступного источника энтропии. Подход подходит, если необходимо изучить интеграцию криптографической библиотеки и UART, однако требует корректной инициализации и повторного заполнения энтропией.

Способ 3. Псевдослучайная последовательность для тестирования

Использовать PRNG с фиксированным начальным значением или тестовый генератор. Это упрощает отладку протокола и проверку передачи данных в Verilator, но не обеспечивает криптографическую безопасность и не должно использоваться для генерации ключей.
